# Sanctuary Linux Launcher v0.1.0 Recovery Build

This release preserves the last known working packaged build of the original Sanctuary Linux Launcher demo.

The launcher was originally developed locally and the original source tree was lost. Development is now continuing in this repository by reconstructing and rebuilding the launcher from the surviving compiled application and debug metadata.

## Included

- Self-contained Linux x64 build
- Avalonia-based launcher UI
- Server selection and connection functionality
- Client verification/update functionality
- Login functionality
- Proton-based Free Realms launching
- Server manifest support
- Saved server/join functionality

## Status

This is a recovery/testing build and should be considered **alpha software**.

The primary purpose of this release is to verify that the surviving original launcher build still functions before redevelopment continues.
